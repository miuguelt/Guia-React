Reflexion Inicial: Por que React?

Entendamos el problema que React resuelve: manipulación ineficiente del DOM.

El problema del DOM manual

Antes de React, actualizar la interfaz requería manipular el DOM manualmente con JavaScript puro o jQuery. Esto causaba codigo propenso a errores, dificil de mantener y con rendimiento inconsistente.

📥 Descargar Proyecto

Descarga y ejecuta la app React

El codigo completo del proyecto esta en recursos/codigo-ejemplo/. Sigue estos pasos para ponerlo en marcha.

📝 Requisitos

  • Node.js 18+ instalado
  • npm (viene con Node.js)
  • La API FastAPI corriendo en http://localhost:8009 (para Fase 3)

🛠 Instrucciones paso a paso

📂Terminal
# 1. Ve a la carpeta del proyecto
cd recursos/codigo-ejemplo

# 2. Instala dependencias
npm install

# 3. Inicia el servidor de desarrollo
npm run dev

🔗 Proxy a la API

El proyecto Vite esta configurado con proxy en vite.config.js. Las llamadas a /api/* se redirigen automaticamente a http://localhost:8009. No necesitas configurar CORS manualmente.

🔍 Probar con pruebas unitarias

📈Terminal
# Ejecutar todas las pruebas
npm test

# Modo watch (se re-ejecutan al guardar)
npm test -- --watch

🎨 Hot Reload incluido

Vite recarga automaticamente el navegador cuando guardas un archivo. Los cambios se ven al instante sin recargar manual.
