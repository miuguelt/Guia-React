Módulo 1

Fundamentos y Mentalidad React

Comprende por qué React transformó el desarrollo web: del DOM manual imperativo al Virtual DOM declarativo.

💡 El Paradigma Declarativo

En JavaScript Vanilla le dices al navegador "busca este botón, cámbiale el texto, busca este div, agrégale esta clase...". En React describes cómo debe lucir la pantalla según los datos (estado), y React actualiza únicamente los nodos modificados.

Reto 1 · Básico

Gestor de Cultivos con Filtro Dinámico

Reto 2 · Avanzado

Asignación de Cultivos a Fincas (N:M)

  • Modal con confirmación de siembra.
  • Mensaje flotante (Toast) tras guardar.
